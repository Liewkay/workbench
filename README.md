# Liewkay's Workbench 🕸️

移动端每日工作台 PWA 应用。

## 功能

- 📊 概览：日期、统计卡片、热点TOP3、今日任务预览
- 🔥 热点新闻：AI新闻、抖音/微博热搜、小红书热搜、选题建议
- 🎈 小红书：笔记创作 + 收藏夹管理（链接解析、批量导入、智能摘要）
- 🗓️ 今日计划：任务增删改、农历日历
- 🍴 饮食打卡：拍照选食物、卡路里统计、71项食物数据库
- 🌱 抖音收藏：链接解析、批量导入、标签管理、内容摘要
- 🪸 学习成长：学习目标追踪、进度可视化
- 📈 每日复盘：每日记录与评分
- 📊 每周复盘：周度总结
- ⚙️ 设置：安卓适配、AI增强、数据管理

## 技术栈

- 纯 HTML/CSS/JS 单文件，无外部依赖
- PWA 支持（可添加到手机桌面，全屏体验）
- localStorage 本地持久化存储
- 红蓝双色调设计

## 访问

打开 GitHub Pages 链接即可使用，支持手机添加到桌面作为 App。
